# ใช้ Ping Pong Counter เป็นเว็บแอป (PWA) บน Mac / คอม / มือถือ

PWA คือเว็บที่ **ติดตั้งเป็นแอปได้** — มีไอคอนใน Dock / หน้าจอหลัก เปิดเป็นหน้าต่างแยก และ **ใช้ได้แม้ไม่มีเน็ต** หลังเปิดครั้งแรก

> ⚠️ ข้อมูล (รายชื่อ สถิติ เกมที่ค้าง) เก็บ **แยกในแต่ละเครื่อง** — ไม่ซิงก์ข้ามเครื่อง

---

## 1. Build

```powershell
npm.cmd run build
```

ได้โฟลเดอร์ `dist\` — นี่คือทั้งแอป (HTML, JS, รูป, ไอคอน, `sw.js`, `manifest.webmanifest`)

ทดสอบในเครื่องตัวเองก่อนได้: `npm.cmd run preview` แล้วเปิด http://localhost:4173

## 2. เอาขึ้นเว็บ (ฟรี)

PWA ต้องเปิดผ่าน **HTTPS** ถึงจะติดตั้งได้ — ส่งไฟล์ `dist` ไปอีกเครื่องแล้วเปิดตรง ๆ **ติดตั้งไม่ได้**
เลือกอย่างใดอย่างหนึ่ง (ทั้งคู่ไม่ต้องมี server เอง):

### ทางเลือก A: Netlify Drop (ง่ายสุด)
1. เปิด <https://app.netlify.com/drop> แล้วสมัคร/ล็อกอิน (ฟรี)
2. ลากโฟลเดอร์ `dist` ไปวางในหน้าเว็บ
3. ได้ลิงก์ เช่น `https://ชื่อสุ่ม.netlify.app` — เปลี่ยนชื่อได้ใน **Site configuration → Change site name**

### ทางเลือก B: Cloudflare Pages
1. เปิด Cloudflare Dashboard → **Workers & Pages → Create → Pages → Upload assets**
2. ตั้งชื่อโปรเจกต์ แล้วอัปโหลดโฟลเดอร์ `dist`
3. ได้ลิงก์ `https://ชื่อโปรเจกต์.pages.dev`

> ไฟล์ `public/_redirects` ตั้งไว้แล้ว — รีเฟรชหน้าไหนก็ไม่ขึ้น 404
> ไม่แนะนำ GitHub Pages แบบ `username.github.io/ชื่อ-repo` เพราะแอปตั้ง path ไว้ที่ `/`

## 3. ส่งให้อีกเครื่อง

ส่ง **ลิงก์** (เช่นทาง LINE) แล้วติดตั้งตามอุปกรณ์:

| อุปกรณ์ | วิธีติดตั้ง |
|---|---|
| **Mac — Safari** (macOS Sonoma ขึ้นไป) | เปิดลิงก์ → เมนู **File → Add to Dock** |
| **Mac / Windows — Chrome, Edge** | เปิดลิงก์ → กดไอคอน **ติดตั้ง** ท้ายช่อง URL (หรือเมนู ⋮ → **Cast, save and share → Install page as app**) |
| **iPhone / iPad — Safari** | เปิดลิงก์ → ปุ่ม **แชร์** → **Add to Home Screen** |
| **Android — Chrome** | เปิดลิงก์ → เมนู ⋮ → **Add to Home screen / Install app** |

เปิดแอปครั้งแรกตอนมีเน็ต 1 ครั้ง หลังจากนั้นใช้ offline ได้

## 4. อัปเดตเวอร์ชันใหม่

1. `npm.cmd run build`
2. อัปโหลด `dist` ใหม่ทับที่เดิม (Netlify: **Deploys → ลากโฟลเดอร์วาง** · Cloudflare: **Create deployment**)
3. เครื่องที่ติดตั้งแล้วจะได้เวอร์ชันใหม่ **เมื่อปิดแอปแล้วเปิดใหม่** (ตั้งใจไม่ให้รีโหลดกลางเกม) — ข้อมูลในเครื่องไม่หาย

## คีย์ลัด (หน้าแข่ง บนคอม / Mac)

| ปุ่ม | ทำอะไร |
|---|---|
| `←` หรือ `A` | แต้มฝั่งแดง |
| `→` หรือ `L` | แต้มฝั่งน้ำเงิน |
| `Backspace` หรือ `Z` | ย้อนแต้มล่าสุด |
| `Enter` | เริ่มเกมถัดไป (ตอนประกาศผู้ชนะ) |
| `Esc` | ปิดเมนูที่เปิดอยู่ |

คีย์ลัดไม่ทำงานระหว่างพิมพ์ชื่อ หรือเมื่อมีเมนูเปิดอยู่
